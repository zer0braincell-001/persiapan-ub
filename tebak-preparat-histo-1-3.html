Tebak preparat: histologi GIT

Tiap foto punya satu pertanyaan dan lima pilihan dari preparat atau struktur tetangga terdekat. Kalau ada jarum penunjuk, yang ditanya struktur yang ditunjuk. Fotonya diambil lewat mikroskop dengan HP (folder drive preparat4), dan labelnya mengikuti nama file pemilik drive, bukan verifikasi aslab. Gambar PPT aslab dan posttest kating tidak dipasang di sini karena web ini publik.

Versi lengkap (103 gambar PPT + drive, posttest kating 50 soal bergambar): halaman latihan pribadi (hanya bisa dibuka akun pemilik).

Kunci cepat: Brunner di submukosa = duodenum · plak Peyer = ileum · tidak keduanya = jejunum · pit dangkal + kelenjar rapat = fundus · pit dalam bergelung = pylorus · tanpa vili + goblet melimpah = crassum · limfoid melingkar + kripte sedikit = appendix · kolumner ke skuamous = recto-anal.
